# 每日財經簡報寄信到 Email（Claude Routine 設定）

讓 Claude **每天自動**把當日「全球財經 + 商業世界」深度簡報寄到你的信箱，
**完全不需要任何 API 金鑰或 GitHub secret** —— 由 Claude 自己上網蒐集、消化成洞察，
再透過 Gmail 連結器寄出。

## 為什麼不用網站的新聞 pipeline？

網站的每日新聞（`briefings.json`）需要外部 LLM 才能把 RSS 原文整理成分級新聞，
在雲端排程環境已停止更新。這個 Routine 改由 **Claude 本身**擔任那個 LLM 角色，
所以不需要 `GEMINI_API_KEY`、不需要付費 API，也不受該 pipeline 卡關影響。

## 一次性設定（約 1 分鐘）

Routine 無法從「Claude Code on the web」的工作階段內建立，必須在網頁 UI 或終端機 CLI 建立：

1. 打開 <https://claude.ai/code/routines> → 點 **New routine**。
2. **Name**：`每日財經簡報寄信`
3. **Prompt / Instructions**：貼上下方「Routine 提示詞」整段。
4. **Repositories**：選 `news-dashboard`（表單需要，本任務其實用不到 repo）。
5. **Environment**：用 **Default**（Trusted 即可 —— Gmail 連結器流量走 Anthropic
   伺服器，不受網路白名單限制）。
6. **Connectors**：保留 **Gmail**，其餘可移除以縮小權限。
7. **Trigger**：選 **Schedule → Daily**，設定你想收信的時間（台北時區自動換算）。
8. **Model**：選最強的模型 —— 這份簡報的價值全在研判品質。
9. 點 **Create**。可先按 **Run now** 測試。

> CLI 替代做法：在終端機（非 web 工作階段）執行 `/schedule`，Claude 會逐步問完並建立。

## Routine 提示詞（原封不動貼上）

```
執行每日財經簡報並寄到我的信箱。收件人：liuaaron1128@gmail.com

【第一步：確認日期】
先確認今天的正確日期（台北時區）。絕對不要從搜尋結果去推斷日期。

【第二步：蒐集資料】用 WebSearch 蒐集最新資料，涵蓋兩大塊：

A. 市場與總體
- 美股（S&P 500、Nasdaq、道瓊）最新收盤與驅動因素
- 美債殖利率（2 年、10 年、30 年）與 Fed 政策預期（升／降息機率、FOMC、官員談話）
- 台股（加權指數、台積電 2330、外資買賣超）
- 匯率、原物料、加密貨幣（BTC／ETH）重點

B. 商業世界（至少佔一半篇幅）
- 併購與資本動向：重大 M&A、私募基金進出、分拆出售
- 企業 AI 落地：導入數據、ROI、失敗率、具體企業案例
- 創投與新創：重要募資輪次，以及它們代表的產業趨勢
- 產業與供應鏈：半導體、AI 基礎設施、產能與設備、關鍵企業戰略
- 重要財報與企業經營動態

【第三步：消化成洞察】用繁體中文撰寫，讀者是一位企業董事長。要求：
- 今日核心研判（3–5 段）：串起各項訊號、明確點出「背離或共振」，並指出
  「市場共識是什麼、我認為哪裡想錯了」。要給判斷，不要只複述數字。
- 市場快照：表格化關鍵數字，標示變動方向。
- 重點新聞 5 則左右，每則採多層結構：
  發生什麼 → 第一序效應 → 第二序效應（多數人沒算到的）→ 對你的意涵
  → 觸發條件 → 觀察點
- 商業世界區塊要有實際數字（金額、百分比、公司名），並做「模式判讀」：
  這些交易合起來說明了什麼趨勢。
- 給董事長的三個問題：本週可立即行動的具體提問。
- 未來一週觀察行事曆。
- 結尾註明資料來源與「僅供參考，非投資建議」。

【第四步：寄信】用 Gmail 的 send_message 寄出：
- 主旨：📊 每日財經簡報 — YYYY/MM/DD（週X）｜<當日最關鍵的一句話>
- HTML 卡片排版：深色漸層標題列（含當日轉折摘要）、核心研判方框（內含
  「我認為市場想錯的地方」高亮框）、市場快照表格、每則新聞獨立卡片並以粗體
  標籤分隔各層、商業數據用表格、深色底的「給董事長的三個問題」區塊、
  觀察行事曆、來源註記。
- 同時提供純文字 body 作為 fallback。

若 Gmail 工具不可用，請直接回報，不要靜默結束。
```

## 品質準則（寫給執行這份任務的 Claude）

- **先查日期再查新聞。** 曾發生過從搜尋結果推斷日期、導致寄出兩週前行情的錯誤。
- **數字要有出處、要最新。** 標明是哪一個交易日的收盤。
- **價值在研判不在轉述。** 每一則都要回答「所以呢？對我有什麼影響？」
- **商業內容不可被市場行情擠掉。** 董事長要的是經營決策情報，不只是盤勢。
- 找不到某塊資料時，明說「今日無重大進展」，不要編造。
